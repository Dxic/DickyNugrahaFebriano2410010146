# Ruang Sela

Project frontend sederhana menggunakan HTML, CSS, dan JavaScript murni.

## Isi project
- `index.html` — struktur halaman
- `style.css` — tampilan modern dan responsif
- `script.js` — timer fokus, task list, catatan lokal, mood selector, jam real-time

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder `ruang-sela`.
3. Klik dua kali `index.html`.
4. Project langsung berjalan di browser tanpa instalasi apa pun.

## Fitur
- Focus timer dengan preset 25, 45, dan 60 menit.
- Task list yang tersimpan otomatis di browser.
- Quick note dengan autosave lokal.
- Mood selector.
- Greeting dan progress hari secara real-time.
- Tampilan responsif untuk laptop dan HP.

Semua data tersimpan di `localStorage` browser, jadi tidak membutuhkan backend.
